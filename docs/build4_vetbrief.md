# Build #4 — VetBrief

VetBrief is derived from persisted workflow state and structured owner observations.

It reports:
- follow-up adherence;
- longitudinal home observations;
- outstanding required actions;
- workflow safety-routing status.

It deliberately does not infer diagnosis, causality, or treatment.

## Commercial validation
Time a veterinary professional performing the same follow-up:
1. from raw owner messages; and
2. from the generated VetBrief.

Primary KPI: time saved per follow-up consultation.
