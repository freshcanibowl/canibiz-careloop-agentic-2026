# Veterinary Pilot Scorecard

Record per test case:
- Raw-message review time (seconds)
- VetBrief review time (seconds)
- Required information items present / expected
- Follow-up actions completed / expected
- Vet usefulness rating (1–5)
- Would use in existing workflow? yes/no
- Would pay / budget owner?
- Biggest blocker
- Missing information
- Unsafe or misleading output observed?

Derived:
- Time saved = raw review time - VetBrief review time
- Completeness = present / expected
- Follow-up completion = completed / expected
